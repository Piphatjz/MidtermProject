# Dig & Treasure (ขุดดินหาสมบัติ) — โปรโตไทป์ Pygame

เกมขุดดินหาสมบัติแนวเดียวกับวิดีโอตัวอย่างที่แนบมา ("Dig It" / เกมมือถือขุดเหมือง)
ตอนนี้เป็น **โปรโตไทป์ระบบเกมครบทุกฟีเจอร์หลัก** โดยใช้รูปทรง/สีแทน asset จริงไปก่อน
ตามที่ตกลงกันไว้ — โครงสร้างโค้ดแยกไฟล์ชัดเจน พร้อมเปลี่ยนรูปทรงสีเป็นรูปภาพ/สไปรต์จริงทีหลังได้ง่าย

## วิธีติดตั้ง & รัน

```bash
pip install -r requirements.txt
python main.py
```

รองรับ Python 3.9+ (ทดสอบกับ Python 3.12 / pygame 2.6.1)

## โหมดการเล่น (Game Modes)

### 1. โหมดคลาสสิก (Classic Endless Mode) — ขุดอิสระไร้ขีดจำกัด ปลดล็อคชั้นความลึก
- เล่นได้ไม่จำกัดรอบ (ไม่มีเงื่อนไขตัดจบอัตโนมัติ) เพื่อให้คุณเพลิดเพลินกับการขุดและพัฒนาประสิทธิภาพรถขุดอย่างเต็มที่
- **ระบบชั้นความลึก (Floor Progression)**:
  - ชั้น 1: **ชั้นดินปนกรวด (Upper Soil)** (0–20ม.) — ดินนุ่ม แร่เหรียญและทอง
  - ชั้น 2: **ชั้นหินตะกอน (Sediment Strata)** (21–45ม.) — เริ่มมีหินแข็งและแหล่งเชื้อเพลิง (ปลดล็อค 300 เหรียญ)
  - ชั้น 3: **ถ้ำคริสตัล (Crystal Caverns)** (46–75ม.) — เพชรและสายแร่ทองคำอุดมสมบูรณ์ (ปลดล็อค 800 เหรียญ)
  - ชั้น 4: **เหมืองหินโบราณ (Ancient Deep)** (76–110ม.) — หินหนาแน่นและสมบัติล้ำค่า (ปลดล็อค 1,800 เหรียญ)
  - ชั้น 5: **แกนพิภพลาวา (Core Abyss)** (111–150ม.) — หินแกนกลางและแร่เพชรจำนวนมาก (ปลดล็อค 3,200 เหรียญ)
  - ชั้น 6+: **ความลึกลึกสุดหยั่ง (Endless Depths)** — สุ่มขยายต่อเนื่องทุก 50 เมตร
- **วิธีปลดล็อคชั้น**:
  - เมื่อขุดลงไปถึงประตูกั้น (Security Barrier) สามารถกด **[E]** เพื่อปลดล็อคได้ทันทีเมื่อเหรียญพอ
  - หรือไปที่ร้านค้า (Shop) แล้วเลือกแท็บ **"ปลดล็อคชั้น"** เพื่อดูข้อมูลชั้นและกดปลดล็อค

### 2. โหมดสัญญาภารกิจ (Mission Contracts Mode)
- สุ่มเลือกสัญญาภารกิจ 3 ระดับ (ง่าย, ปานกลาง, ยาก) หรือสุ่มภารกิจอิสระ
- มีเงื่อนไขเป้าหมายผสม (ขุดเพชร, ทอง, ดำดิ่งความลึก, จำนวนเที่ยวกลับบ้าน ฯลฯ) เมื่อครบจะชนะภารกิจ

## ระบบอู่แต่งรถขุด (Garage & Customization)
- เข้าได้จากหน้าเมนูหลัก หรือแท็บในร้านค้า
- **4 ตัวถัง (Chassis)**: Standard, Scout (ไวแต่น้อย), Titan (ถังใหญ่ พลังงานสูง), Hover (ลอยตัวประหยัดแรง)
- **5 หัวขุดพิเศษ (Drill Heads)**:
  - Spiral Auger (มาตรฐาน)
  - Titanium Diamond (เจาะหินได้ทันทีตั้งแต่ Lv.1)
  - Plasma Cutter (พลังเจาะสูง +65%)
  - Magnetic Vortex (ขายแร่ได้ราคาสูงขึ้น +25%)
  - Seismic Hammer (ระยะเจาะไกล 2 ช่องทันที)
- **4 สีตัวรถ (Colors)**: Industrial Yellow, Ruby Red, Cyber Blue, Stealth Carbon

## การควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| ลูกศร / WASD | บังคับรถขุด (W/↑ บินขึ้น, S/↓ เจาะลง, A/← ซ้าย, D/→ ขวา) |
| Shift / Spacebar | **Turbo Boost & Ground Slam**: เร่งความเร็ว 2.6x และเพิ่มแรงเจาะกระแทก 3.0x |
| E | **Interact**: เปิด/ปิดร้านค้า (เมื่ออยู่หน้าร้าน) หรือปลดล็อคประตูกั้นชั้นความลึก |
| H / F1 | เปิด/ปิดหน้าต่าง **วิธีเล่น & ปุ่มควบคุม (How to Play)** |
| กดเมาส์ค้าง | รถขุดจะเคลื่อนที่/เจาะไปทางทิศที่ชี้เมาส์ |
| ESC | เปิดเมนูหยุดชั่วคราว (Pause) หรือย้อนกลับ |
| F11 | สลับโหมดเต็มจอ (Fullscreen toggle) |
