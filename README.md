# ⛏️ Dig & Treasure (ขุดดินหาสมบัติ)

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://www.python.org/)
[![Pygame](https://img.shields.io/badge/Pygame-2.5%2B-green.svg)](https://www.pygame.org/)
[![Tests](https://img.shields.io/badge/Automated%20Tests-Passing%20100%25-brightgreen.svg)](test_game.py)
[![License](https://img.shields.io/badge/License-MIT-orange.svg)](LICENSE)

**Dig & Treasure** เป็นเกม 2D Action Mining & Resource Management พัฒนาด้วยภาษา Python ร่วมกับ Pygame ได้รับแรงบันดาลใจจากเกมคลาสสิกอย่าง *Motherload* และ *SteamWorld Dig* 

ผู้เล่นจะรับบทเป็นผู้บังคับรถขุดเจาะ (Drill Vehicle) ดำดิ่งสำรวจลงไปในชั้นดินและหินใต้ผืนพิภพ ค้นหาทรัพยากรมีค่า (เหรียญแร่, ทองคำ, เพชรพลอย, และกระป๋องน้ำมัน) นำกลับขึ้นมาขายที่ฐานบนผิวดินเพื่อสะสมเงินทุน อัปเกรดประสิทธิภาพรถขุด ปรับแต่งตัวถังและหัวขุดในอู่ (Garage) เพื่อพิชิตภารกิจสัญญา หรือขุดลึกลงสู่แกนพิภพแบบไร้ขีดจำกัดในโหมดคลาสสิก

## ✨ คุณสมบัติเด่นของเกม (Key Features)

1. **2 โหมดการเล่นเลือกได้ตามสไตล์ (Dual Game Modes)**:
   - **Mission Contracts Mode**: สุ่มภารกิจสัญญา 3 ระดับความยาก (*Easy, Medium, Hard*) พร้อมระบบติดตามเป้าหมายแบบเรียลไทม์
   - **Classic Endless Mode**: ขุดเล่นได้ไม่จำกัดรอบ ปลดล็อคประตูกั้นชั้นความลึก (*Security Barriers*) ลงไปเรื่อยๆ ไร้ขีดจำกัด
2. **ฟิสิกส์การขุดเนียนตา & Gravity Slam**:
   - ระบบ **Auto-Centering** ปรับตำแหน่งรถเข้ากึ่งกลางช่องอุโมงค์อัตโนมัติ
   - ระบบ **Gravity Slam**: สะสมพลังงานศักย์จากการบินขึ้น เพื่อพุ่งกระแทกขุดบล็อกด้วยความเร็ว `2.6x` และแรงเจาะ `3.0x`
3. **ระบบแต่งรถและการอัปเกรดลึก (Garage & Progression)**:
   - อัปเกรดสเตตัส 4 ด้าน (*Power, Capacity, Energy, Speed*) ได้ถึง `Lv.6`
   - ตัวถังรถขุด 4 แบบ (*Standard, Scout, Titan, Hover-Pod*) และสีตัวถัง 8 สี
   - หัวขุดพิเศษ 5 แบบพร้อมสกิลประจำตัว (*Spiral, Diamond, Plasma, Vortex, Seismic*)
4. **Procedural Underground World**:
   - แผนที่สุ่มสร้างชั้นดิน หินแข็ง และสายแร่ตามความลึก (กว้าง 15 ช่อง ลึก 650 ช่อง)
   - ระบบ HP ของบล็อกและสไปรต์รอยแตก 3 ระดับ (`crack_1` – `crack_3`) แสดงความเสียหายอย่างสมจริง
5. **Resolution-Independent Display & Fullscreen**:
   - เรนเดอร์บน Virtual Surface ขนาดคงที่ `720 × 810` ย่อ/ขยายภาพและสลับเต็มจอ (`F11`) ได้โดยไม่เสียอัตราส่วนภาพ
6. **Self-Contained Procedural Asset Generation**:
   - สคริปต์ `assets_gen.py` วาดสไปรต์ PNG ด้วย Pillow และสังเคราะห์เสียงเอฟเฟกต์ WAV 12 เสียงด้วยสมการคลื่นคณิตศาสตร์ 100%

## 📥 วิธีติดตั้งและเริ่มเล่น (Installation & Setup)

### ข้อกำหนดเบื้องต้น (Prerequisites)
- **Python 3.9+** (รองรับ Python 3.9, 3.10, 3.11, 3.12)
- **Pygame 2.5+**
- **Pillow (PIL)** (สำหรับใช้สร้างสไปรต์ภาพอัตโนมัติ)

### ขั้นตอนการติดตั้ง (Installation Steps)

1. **Clone หรือ ดาวน์โหลด Repository**:
   ```bash
   git clone https://github.com/Piphatjz/MidtermProject.git
   cd MidtermProject
   ```

2. **ติดตั้ง Dependencies ที่จำเป็น**:
   ```bash
   pip install -r requirements.txt
   ```

3. **เริ่มต้นเล่นเกม**:
   ```bash
   python main.py
   ```

## 🎮 วิธีเล่นและการบังคับ (Controls & Gameplay Guide)

### ปุ่มควบคุมทั้งหมด (Controls Reference)

| ปุ่มควบคุม | การทำงาน |
| :--- | :--- |
| **`W` / `A` / `S` / `D`** หรือ **ปุ่มลูกศร** | บังคับทิศทางรถขุด (ขึ้น / ซ้าย / ลง / ขวา) |
| **คลิกเมาส์ซ้ายค้าง** | บังคับรถขุดเคลื่อนที่และขุดไปตามทิศทางของเคอร์เซอร์เมาส์ |
| **`Shift`** หรือ **`Spacebar`** | เปิดใช้งาน **Turbo Boost** (เร่งสปีด `2.6x`) และ **Gravity Slam** (เจาะกระแทก `3.0x`) |
| **`E`** | **Interact**: เปิดร้านค้า & อู่แต่งรถ (หน้าร้านผิวดิน) หรือกดปลดล็อคประตูกั้นชั้น |
| **`H`** หรือ **`F1`** | เปิด/ปิดหน้าต่าง **คู่มือวิธีเล่น & ปุ่มควบคุม (How to Play)** |
| **`M`** | เปิด/ปิดเสียงเกม (Mute / Unmute) |
| **`F11`** | สลับโหมดเต็มจอ (Fullscreen Toggle) |
| **`ESC`** | เมนูหยุดชั่วคราว (Pause Menu) หรือย้อนกลับ |

### วงจรเกมเพลย์ (Gameplay Loop)
```text
[ลงเหมืองขุดเจาะ] ➡️ [เก็บแร่ & น้ำมัน] ➡️ [ขับกลับบ้านบนผิวดิน] ➡️ [ขายแร่ & เติมพลังงานฟรี] ➡️ [อัปเกรด & แต่งรถ]
```

## 🚗 ระบบอู่แต่งรถและหัวขุดพิเศษ (Garage & Customization)

ผู้เล่นสามารถเข้าอู่แต่งรถได้จาก **หน้าร้านค้า (`E`)** หรือ **หน้าเมนูหลัก** เพื่อปรับแต่งรถขุด:

### 1. ตัวถังรถขุด 4 สไตล์ (Chassis Types)
- 🚜 **Standard Excavator**: ตัวถังมาตรฐาน สมดุลรอบด้าน
- 🏎️ **Scout Buggy**: ตัวถังน้ำหนักเบา ความเร็วเคลื่อนที่ `+20%`
- 🐘 **Titan Crawler**: ตัวถังยักษ์เพิ่มความจุถังแร่ `+50%` และความจุพลังงาน `+30%`
- 🛸 **Hover-Pod**: ยานลอยตัวไร้แรงเสียดทาน ประหยัดพลังงานจากการบิน `+35%`

### 2. หัวขุดพิเศษ 5 แบบ (Drill Heads & Abilities)
- 🌀 **Spiral Auger (มาตรฐาน)**: หัวเจาะเกลียวประหยัดพลังงาน ไว้วางใจได้เสมอ
- 💎 **Titanium Rock-Crusher (หัวเพชร)**: ** Bedrock Breaker** — เจาะหินแข็งได้ทันทีตั้งแต่เริ่มเกมโดยไม่ต้องรออัปเกรด + เจาะหินแรงขึ้น `+50%`
- ⚡ **Plasma Laser Cutter (หัวพลาสม่า)**: ** Superheated Melter** — ลำแสงความร้อนสูง เพิ่มแรงเจาะดิน `+65%` (เจาะไวมาก)
- 🧲 **Magnetic Vortex Drill (หัวแม่เหล็ก)**: ** Fortune Attractor** — ขายแร่ได้ราคาสูงขึ้น `+25%` และสุ่มดูดแร่/น้ำมันจากดินว่าง
- 💥 **Seismic Hammer Head (หัวคลื่นสั่นสะเทือน)**: ** Seismic Cleave** — คลื่นกระแทกขุดบล็อกข้างเคียงพร้อมกันวงกว้าง 3 ช่อง

## 🎯 โหมดการเล่น (Game Modes)

### 1. โหมดสัญญาภารกิจ (Mission Contracts Mode)
- เลือกลองสัญญาภารกิจประจำตา 3 ระดับความยาก (*Easy, Medium, Hard*)
- เป้าหมายประกอบด้วยเงื่อนไขผสม (เช่น ขุดเพชร 4 เม็ด + ขุดลึก 40m + สะสม 500 เหรียญ)
- ต้องบรรลุเงื่อนไขครบทุกข้อ แล้วขับรถกลับมาจอดที่ **บ้าน (Home)** บนผิวดินเพื่อรับชัยชนะ

### 2. โหมดคลาสสิก (Classic Endless Mode)
- เล่นได้ไม่จำกัดรอบ เพื่อสะสมเงินพัฒนาประสิทธิภาพรถขุด
- **ประตูกั้นชั้นความลึก (Security Barriers)**:
  - **ชั้น 1 (0–20m)**: ผิวดิน & แร่อ่อน (ปลดล็อคฟรี)
  - **ชั้น 2 (21–45m)**: หินตะกอน & สายแร่ทอง (ปลดล็อค 300 เหรียญ)
  - **ชั้น 3 (46–75m)**: ถ้ำคริสตัล & อัญมณีลึก (ปลดล็อค 800 เหรียญ)
  - **ชั้น 4 (76–110m)**: เหมืองหินโบราณ (ปลดล็อค 1,800 เหรียญ)
  - **ชั้น 5 (111–150m)**: แกนพิภพลาวา (ปลดล็อค 3,200 เหรียญ)
  - **ชั้น 6+**: Endless Depths (ขยายต่อเนื่องทุก 50m)

## 💎 ระบบทรัพยากรและการอัปเกรด (Resources & Upgrades)

### ประเภททรัพยากร (Resources)
- 🪙 **เหรียญแร่ (Coin)**: มูลค่า `2G` พบได้ทั่วไปในชั้นตื้น
- 🥇 **ทองคำ (Gold)**: มูลค่า `5G` พบในชั้นกลางถึงชั้นลึก
- 💎 **เพชรพลอย (Diamond)**: มูลค่า `20G` พบในชั้นหินและถ้ำลึก
- ⛽ **กระป๋องน้ำมัน (Fuel Canister)**: ไม่สามารถขายได้ แต่เก็บแล้ว **เติมพลังงานทันที +40 หน่วย**

### สายการอัปเกรด 4 ด้าน (Shop Upgrades)
- ⛏️ **Power (พลังเจาะ)**: เพิ่มความเร็วในการเจาะบล็อกดินและหินแข็ง
- 📦 **Capacity (ความจุถัง)**: เพิ่มช่องเก็บแร่ในถังรถขุด
- ⚡ **Energy (พลังงาน)**: เพิ่มความจุถังพลังงานให้ขุดได้นานขึ้น
- 🏎️ **Speed (ความเร็ว)**: เพิ่มความเร็วในการบินและขับเคลื่อนบนผิวดิน
