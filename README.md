# Dig & Treasure (ขุดดินหาสมบัติ) — โปรโตไทป์ Pygame

เกมขุดดินหาสมบัติแนวเดียวกับวิดีโอตัวอย่างที่แนบมา ("Dig It" / เกมมือถือขุดเหมือง)
ตอนนี้เป็น **โปรโตไทป์ระบบเกมครบทุกฟีเจอร์หลัก** โดยใช้รูปทรง/สีแทน asset จริงไปก่อน
ตามที่ตกลงกันไว้ — โครงสร้างโค้ดแยกไฟล์ชัดเจน พร้อมเปลี่ยนรูปทรงสีเป็นรูปภาพ/สไปรต์จริงทีหลังได้ง่าย

## วิธีติดตั้ง & รัน

```bash
pip install -r requirements.txt
python main.py
```

รองรับ Python 3.9+ (ทดสอบกับ Python 3.12 / pygame 2.6.1)

## การควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| ลูกศร / WASD | บังคับรถขุดขึ้น-ลง-ซ้าย-ขวา |
| กดเมาส์ค้าง | รถขุดจะเคลื่อนที่/เจาะไปทางทิศที่ชี้เมาส์ |
| E | เปิด/ปิดร้านอัพเกรด (ต้องยืนอยู่หน้าร้าน) |
| ESC | เปิดเมนูหยุดชั่วคราว (Pause) |

## ฟีเจอร์ที่ทำไว้ครบตามที่ขอ

1. **ฉากใต้ดิน** — พื้นดินเป็นกริดสุ่ม มีทรัพยากร 3 ชนิดฝังอยู่ (เงิน/ทอง/เพชร มูลค่าไม่เท่ากัน)
   และมีหิน (rock) ที่แข็งกว่าดินปกติ ต้องอัพเกรดหัวขุดถึงระดับหนึ่งก่อนถึงจะเจาะได้
   มี **บ้าน/ฐาน** สำหรับขายทรัพยากรที่เก็บมา + เติมพลังงานฟรีทุกครั้งที่กลับบ้าน
   และ **ร้านอัพเกรด** อยู่ข้างบ้าน
2. **บังคับด้วยเมาส์หรือคีย์บอร์ดได้ทั้งคู่** ตามที่ระบุ
3. **ความจุจำกัด + พลังงานจำกัด** — แถบพลังงานและแถบความจุแสดงที่ HUD มุมขวาบน
   ถ้าถังเต็มจะเก็บเพิ่มไม่ได้ (ต้องกลับบ้านขาย) ถ้าพลังงานหมดรถจะขยับไม่ได้
4. **จุดจบเกมกำหนดได้เอง** (ปรับได้ที่ `settings.py`):
   - พลังงานหมดระหว่างอยู่นอกบ้าน → **Game Over**
   - เก็บเหรียญสะสมครบเป้าหมาย (`VICTORY_COIN_TARGET`) → **Victory**
   - กด ESC แล้วเลือก "บันทึกและออก" → เซฟเกม (JSON) แล้วกลับเมนู, เข้าเกมใหม่แล้วกด **Continue** เพื่อเล่นต่อจากจุดเดิมได้

## ระบบอัพเกรด (ที่ร้าน กด E ตอนยืนหน้าร้าน)

- **ถังเก็บ (Capacity)** — เพิ่มจำนวนทรัพยากรที่บรรทุกได้ต่อรอบ
- **ถังพลังงาน (Energy)** — เพิ่มพลังงานสูงสุด
- **หัวขุด (Power)** — เจาะเร็วขึ้น และเป็นเงื่อนไขให้เจาะหินแข็ง (rock) ได้ (ต้องถึง Lv.2)
- **มอเตอร์ (Speed)** — เคลื่อนที่เร็วขึ้น

ราคาจะเพิ่มขึ้นเรื่อย ๆ ตามระดับ (ปรับสูตรได้ใน `UPGRADES` ที่ `settings.py`)

## โครงสร้างไฟล์

```
dig_game/
├── main.py           # entry point, game loop
├── settings.py        # ค่าคงที่ทั้งหมด (ปรับจูนเกมจากไฟล์เดียว)
├── world.py           # สร้าง/จัดการกริดใต้ดิน, ทรัพยากร, ความคงทนของช่อง
├── vehicle.py         # รถขุด: การเคลื่อนที่, เจาะดิน, พลังงาน, ความจุ, อัพเกรด
├── ui.py              # การวาดทุกอย่าง: โลก, HUD, เมนู, ร้านค้า, หน้าจบเกม
├── game.py            # state machine หลัก (เมนู/เล่น/หยุด/ร้าน/จบเกม) + ผูกทุกส่วนเข้าด้วยกัน
├── save_manager.py    # บันทึก/โหลดเกมเป็น JSON
└── requirements.txt
```

## สิ่งที่ยังเป็น placeholder (รอใส่ asset จริง)

- ทุกอย่างวาดด้วย `pygame.draw` (สี่เหลี่ยม/วงกลม/สามเหลี่ยม) ล้วน ๆ ยังไม่มีรูปภาพ/สไปรต์จริง
- รถขุดยังไม่มีแอนิเมชันล้อหมุน/ระเบิดฝุ่นตอนเจาะ (มีแค่วงกลมสั่นแทนหัวสว่าน)
- ยังไม่มีเสียง (SFX/เพลงประกอบ)
- แผนที่สุ่มใหม่ทุกครั้งที่ "เริ่มเกมใหม่" (ยังไม่มีระบบด่าน/หลายฉาก)

จุดที่ควรทำต่อ (เมื่อพร้อมใส่ asset จริง): แก้ฟังก์ชันใน `ui.py` (`draw_world`, `draw_vehicle`,
`draw_home_and_shop`, `_draw_resource`) ให้ blit รูปภาพแทนการวาดรูปทรง — โครงสร้างพิกัด/กริด
ที่เหลือใช้ได้เหมือนเดิมทั้งหมด ไม่ต้องแก้ลอจิกเกม
