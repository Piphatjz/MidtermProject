# Dig & Treasure (เกมขุดดินหาสมบัติ)

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://www.python.org/)
[![Pygame](https://img.shields.io/badge/Pygame-2.5%2B-green.svg)](https://www.pygame.org/)
[![Tests](https://img.shields.io/badge/Automated%20Tests-Passing%20100%25-brightgreen.svg)](test_game.py)
[![License](https://img.shields.io/badge/License-Com%20Sci%20Chula-red.svg)](#สิทธิ์การใช้งาน-license)

Dig & Treasure เป็นเกมแนว 2D Action Mining & Resource Management ที่พัฒนาด้วยภาษา Python และ Pygame ได้รับแรงบันดาลใจจากเกมคลาสสิกอย่าง Motherload และ SteamWorld Dig

ผู้เล่นจะรับบทเป็นผู้บังคับรถขุดเจาะ (Drill Vehicle) สำรวจลงไปในชั้นดินและหินใต้ผืนพิภพเพื่อค้นหาทรัพยากรมีค่า เช่น เหรียญแร่ ทองคำ เพชรพลอย และกระป๋องน้ำมัน นำกลับขึ้นมาขายที่ฐานบนผิวดินเพื่อสะสมเงินทุน อัปเกรดประสิทธิภาพรถขุด ปรับแต่งตัวถังและหัวขุดในอู่ (Garage) เพื่อพิชิตภารกิจสัญญา หรือขุดลึกลงสู่แกนพิภพแบบไร้ขีดจำกัดในโหมดคลาสสิก

## คุณสมบัติเด่นของเกม

1. **2 โหมดการเล่นเลือกได้ตามสไตล์ (Dual Game Modes)**:
   - **Mission Contracts Mode**: สุ่มภารกิจสัญญา 3 ระดับความยาก (Easy, Medium, Hard) พร้อมระบบติดตามเป้าหมายแบบเรียลไทม์
   - **Classic Endless Mode**: ขุดเล่นได้ไม่จำกัดรอบ ปลดล็อคประตูกั้นชั้นความลึก (Security Barriers) ลงไปเรื่อยๆ ไร้ขีดจำกัด
2. **ฟิสิกส์การขุดเนียนตา & Gravity Slam**:
   - ระบบ **Auto-Centering** ปรับตำแหน่งรถเข้ากึ่งกลางช่องอุโมงค์อัตโนมัติเมื่อขุดแนวดิ่ง
   - ระบบ **Gravity Slam**: สะสมพลังงานศักย์จากการบินขึ้น เพื่อพุ่งกระแทกขุดบล็อกด้วยความเร็ว 2.6x และแรงเจาะ 3.0x
3. **ระบบแต่งรถและการอัปเกรดลึก (Garage & Progression)**:
   - อัปเกรดสเตตัส 4 ด้าน (Power, Capacity, Energy, Speed) ได้ถึง Lv.6
   - ตัวถังรถขุด 4 แบบ (Standard, Scout Buggy, Titan Crawler, Hover-Pod) และสีตัวถัง 8 สี
   - หัวขุดพิเศษ 5 แบบพร้อมสกิลประจำตัว (Spiral, Diamond, Plasma, Vortex, Seismic)
4. **Procedural Underground World**:
   - แผนที่สุ่มสร้างชั้นดิน หินแข็ง และสายแร่ตามความลึก (กว้าง 15 ช่อง ลึก 650 ช่อง)
   - ระบบ HP ของบล็อกและสไปรต์รอยแตก 3 ระดับ (crack_1 ถึง crack_3) แสดงความเสียหายอย่างสมจริง
5. **Resolution-Independent Display & Fullscreen**:
   - เรนเดอร์บน Virtual Canvas ขนาดคงที่ 720 x 810 ย่อและขยายภาพพร้อมสลับเต็มจอ (F11) ได้โดยไม่เสียอัตราส่วนภาพ
6. **Self-Contained Asset Generation**:
   - สคริปต์ assets_gen.py วาดสไปรต์ PNG ด้วย Pillow และสังเคราะห์เสียงเอฟเฟกต์ WAV 12 เสียงด้วยสมการคลื่นคณิตศาสตร์ 100%

## วิธีติดตั้งและเริ่มเล่น

### ข้อกำหนดเบื้องต้น (Prerequisites)
- Python 3.9 ขึ้นไป (รองรับ 3.9, 3.10, 3.11, 3.12)
- Pygame 2.5.0 ขึ้นไป
- Pillow (PIL)

### ขั้นตอนการติดตั้ง (Installation Steps)

1. **Clone หรือดาวน์โหลด Repository**:
   ```bash
   git clone https://github.com/Piphatjz/MidtermProject.git
   cd MidtermProject
   ```

2. **ติดตั้ง Dependencies ที่จำเป็น**:
   ```bash
   pip install -r requirements.txt
   ```

3. **เริ่มต้นเล่นเกม**:
   ```bash
   python main.py
   ```

## ระบบอู่แต่งรถและสเปกรถขุด

ผู้เล่นสามารถเข้าอู่แต่งรถได้จากหน้าร้านค้า (E) หรือหน้าเมนูหลัก เพื่อปรับแต่งรถขุด:

### 1. ตัวถังรถขุด 4 สไตล์ (Chassis Types)
- **Standard Excavator**: ตัวถังมาตรฐาน สมดุลรอบด้าน
- **Scout Buggy**: ตัวถังน้ำหนักเบา ความเร็วเคลื่อนที่ +20%
- **Titan Crawler**: ตัวถังยักษ์เพิ่มความจุถังแร่ +50% และความจุพลังงาน +30%
- **Hover-Pod**: ยานลอยตัวไร้แรงเสียดทาน ประหยัดพลังงานจากการบิน +35%

### 2. หัวขุดพิเศษ 5 แบบ (Drill Heads & Passive Abilities)
- **Spiral Auger (มาตรฐาน)**: หัวเจาะเกลียวประหยัดพลังงาน ไว้วางใจได้เสมอ
- **Titanium Rock-Crusher (หัวเพชร)**: สกิล Bedrock Breaker - เจาะหินแข็งได้ทันทีตั้งแต่เริ่มเกมโดยไม่ต้องรออัปเกรด + เจาะหินแรงขึ้น +50%
- **Plasma Laser Cutter (หัวพลาสม่า)**: สกิล Superheated Melter - ลำแสงความร้อนสูง เพิ่มแรงเจาะดิน +65% (เจาะไวมาก)
- **Magnetic Vortex Drill (หัวแม่เหล็ก)**: สกิล Fortune Attractor - ขายแร่ได้ราคาสูงขึ้น +25% และสุ่มดูดแร่หรือน้ำมันจากดินว่าง
- **Seismic Hammer Head (หัวคลื่นสั่นสะเทือน)**: สกิล Seismic Cleave - คลื่นกระแทกขุดบล็อกข้างเคียงพร้อมกันวงกว้าง 3 ช่อง

## ระบบทรัพยากรและการอัปเกรด

### ประเภททรัพยากร (Resources)
- **เหรียญแร่ (Coin)**: มูลค่า 2G พบได้ทั่วไปในชั้นตื้น
- **ทองคำ (Gold)**: มูลค่า 5G พบในชั้นกลางถึงชั้นลึก
- **เพชรพลอย (Diamond)**: มูลค่า 20G พบในชั้นหินและถ้ำลึก
- **กระป๋องน้ำมัน (Fuel Canister)**: มูลค่า 0G ไม่สามารถขายได้ แต่เก็บแล้วเติมพลังงานทันที +40 หน่วย

### สายการอัปเกรด 4 ด้าน (Shop Upgrades)
- **Power (พลังเจาะ)**: เพิ่มความเร็วในการเจาะบล็อกดินและหินแข็ง
- **Capacity (ความจุถัง)**: เพิ่มช่องเก็บแร่ในถังรถขุด
- **Energy (พลังงาน)**: เพิ่มความจุถังพลังงานให้ขุดได้นานขึ้น
- **Speed (ความเร็ว)**: เพิ่มความเร็วในการบินและขับเคลื่อนบนผิวดิน

## โหมดการเล่น

### 1. โหมดสัญญาภารกิจ (Mission Contracts Mode)
- เลือกลองสัญญาภารกิจประจำตา 3 ระดับความยาก (Easy, Medium, Hard)
- เป้าหมายประกอบด้วยเงื่อนไขผสม (เช่น ขุดเพชร 4 เม็ด + ขุดลึก 40m + สะสม 500 เหรียญ)
- ต้องบรรลุเงื่อนไขครบทุกข้อ แล้วขับรถกลับมาจอดที่บ้าน (Home) บนผิวดินเพื่อรับชัยชนะ

### 2. โหมดคลาสสิก (Classic Endless Mode)
- เล่นได้ไม่จำกัดรอบ เพื่อสะสมเงินพัฒนาประสิทธิภาพรถขุด
- ประตูกั้นชั้นความลึก (Security Barriers):
  - **ชั้น 1 (0-20m)**: ผิวดิน & แร่อ่อน (ปลดล็อคฟรี)
  - **ชั้น 2 (21-45m)**: หินตะกอน & สายแร่ทอง (ปลดล็อค 300 เหรียญ)
  - **ชั้น 3 (46-75m)**: ถ้ำคริสตัล & อัญมณีลึก (ปลดล็อค 800 เหรียญ)
  - **ชั้น 4 (76-110m)**: เหมืองหินโบราณ (ปลดล็อค 1,800 เหรียญ)
  - **ชั้น 5 (111-150m)**: แกนพิภพลาวา (ปลดล็อค 3,200 เหรียญ)
  - **ชั้น 6+**: Endless Depths (ขยายต่อเนื่องทุก 50m)

## โครงสร้างโปรเจกต์

```text
MidtermProject/
├── main.py               # Application entry point, 60 FPS Game Loop, Resolution Scaling
├── settings.py           # ค่าคงที่สมดุลเกมทั้งหมด (Game Balance, Colors, Prices, Hardness)
├── game.py               # Core State Machine (MENU, CONTRACT, PLAYING, SHOP, GARAGE, PAUSED)
├── world.py              # Procedural Grid, HP บล็อก, อัตราเกิดแร่ตามความลึก, ประตูกั้นชั้น
├── vehicle.py            # ฟิสิกส์การเคลื่อนที่, Auto-centering, การเจาะบล็อก, Gravity Slam, อัปเกรด
├── missions.py           # ระบบภารกิจผสม 3 ระดับความยาก และระบบติดตามเป้าหมาย (Progress Tracker)
├── ui.py                 # การวาด HUD 3 โซน, สไปรต์รถ/หัวขุด, เมนูร้านค้า & อู่แต่งรถ, Hints & Toast
├── particles.py          # ระบบเอฟเฟกต์อนุภาค (เศษดิน, ประกายไฟ, ควัน, คลื่นสั่นสะเทือน) และ Floating Text
├── assets.py             # ระบบแคชรูปภาพ และแคชเสียงพร้อม Cooldown ป้องกันเสียงเล่นซ้อน
├── assets_gen.py         # สคริปต์วาดภาพ PNG และสร้างไฟล์เสียง WAV สังเคราะห์ 12 เสียงด้วยคณิตศาสตร์
├── save_manager.py       # ระบบเซฟ/โหลดเกมเป็นไฟล์ JSON (savegame.json)
├── test_game.py          # ชุดทดสอบอัตโนมัติแบบ Headless (100% Passed)
├── CODE_PRESENTATION_GUIDE.md # คู่มือนำเสนอโครงสร้างโค้ดสำหรับ Mentor/อาจารย์
├── SYSTEM_DOCUMENTATION.md    # เอกสารสถาปัตยกรรมและรายละเอียดทางเทคนิคฉบับเต็ม
└── requirements.txt      # รายการไลบรารีภายนอกที่ต้องใช้ (pygame, pillow)
```

## การทดสอบระบบอัตโนมัติ

โปรเจกต์มีชุดทดสอบจำลองเกมเพลย์อัตโนมัติ (test_game.py) ที่สามารถรันได้ในโหมด Headless (ไม่ต้องเปิดหน้าต่าง GUI) เพื่อตรวจสอบความถูกต้องของระบบทั้งหมด:

```bash

```

### รายการที่ได้รับการตรวจสอบในชุดทดสอบ:
- การโหลดสินทรัพย์ภาพและเสียงทั้งหมดครบถ้วน
