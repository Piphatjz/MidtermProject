### 1. What Game Did You Choose? (เลือกสร้างเกมอะไร?)
**Dig & Treasure (ขุดดินหาสมบัติ)** — เกม 2D Action Mining & Resource Management (แรงบันดาลใจจาก *Motherload* และ *SteamWorld Dig*) ผู้เล่นบังคับรถขุดเจาะสำรวจชั้นดินและหินใต้พิภพเพื่อค้นหาแร่มีค่า นำกลับมาขายที่ฐานบนผิวดินเพื่ออัปเกรดสเตตัส ปรับแต่งรถขุดในอู่ (Garage) และพิชิตภารกิจหรือดำดิ่งสู่ชั้นความลึกไร้ขีดจำกัด

### 2. Game Rules (กติกาการเล่น)
* **การบังคับและขุดเจาะ**: ใช้ปุ่ม `WASD` / `ลูกศร` / `เมาส์ซ้าย` เคลื่อนที่และเจาะบล็อก (**หญ้า/ดิน** เจาะได้ทันที, **หินแข็ง** ต้องใช้หัวขุด `Lv.2+` หรือหัวเจาะเพชร) กด `Shift`/`Space` เพื่อใช้ **Turbo & Gravity Slam** เร่งความเร็ว (`2.6x`) และแรงเจาะ (`3.0x`)
* **พลังงานและถังแร่**: การเคลื่อนที่และขุดจะลด **พลังงาน (Energy)** เก็บ **กระป๋องน้ำมัน** ใต้ดินเพื่อเติม `+40` หน่วย แร่ที่ขุดได้ (**เหรียญ** `2G`, **ทอง** `5G`, **เพชร** `20G`) จะเก็บเข้าถังจนเต็ม
* **ฐานบ้านและร้านค้าบนพื้นผิว**: ขับกลับ **บ้าน (Home)** บนผิวดินเพื่อขายแร่ทั้งหมดและ **เติมพลังงานฟรี 100%** จอดหน้า **ร้านค้า (Shop)** แล้วกด `E` เพื่ออัปเกรดรถ ปลดล็อคชั้น หรือเข้าอู่แต่งรถ (`Garage`)
* **เงื่อนไขชนะ/แพ้ตามโหมดการเล่น**:
  * **โหมดภารกิจ (Mission Mode)**: **ชนะ** เมื่อทำภารกิจครบทั้ง 3 เป้าหมายและขับกลับถึงบ้าน / **แพ้ (Game Over)** เมื่อพลังงานหมดนอกฐานบ้าน
  * **โหมดคลาสสิก (Classic Mode)**: ขุดสะสมเหรียญเพื่อปลดล็อคประตูกั้นชั้นความลึกลงไปเรื่อยๆ แบบไม่มีลิมิตชั้น / **แพ้ (Game Over)** เมื่อพลังงานหมดนอกฐานบ้านเช่นกัน

### 3. List of Features (ฟีเจอร์ทั้งหมดในเกม)
1. **2 โหมดการเล่น (Dual Modes)**: **Mission Contracts** (12 ภารกิจ 3 ระดับความยาก: *Easy, Medium, Hard*) และ **Classic Endless Mode** (ระบบชั้นความลึกไร้ขีดจำกัดพร้อมประตูกั้นนิรภัย `Security Barriers`)
2. **แผนที่ใต้ดินแบบสุ่ม (Procedural World)**: สุ่มชั้นดิน หินแข็ง โพรงถ้ำ และอัตราเกิดแร่ตามความลึก พร้อมสไปรต์รอยร้าวบล็อก 3 ระดับตาม HP ที่ลดลง
3. **ฟิสิกส์การขุดและเทอร์โบ (Physics & Gravity Slam)**: ระบบดึงรถเข้ากึ่งกลางช่องอุโมงค์อัตโนมัติ (Auto-Centering) และระบบสะสมพลังงานศักย์เมื่อบินขึ้นเพื่อพุ่งกระแทกเจาะบล็อกแนวดิ่ง
4. **ระบบอัปเกรด 4 ด้าน (Upgrade System)**: อัปเกรด **พลังเจาะ (Power)**, **ความจุถัง (Capacity)**, **ถังพลังงาน (Energy)**, และ **ความเร็ว (Speed)** ได้ถึง `Lv.6` พร้อมคำนวณระดับ `Overall Tier`
5. **อู่แต่งรถและระบบปลดล็อค (Garage & Progression Unlocks)**: ปลดล็อคของแต่งด้วย **เงื่อนไขความก้าวหน้า + เหรียญ**:
   * **สีรถ 8 สี** (*Yellow, Blue, Red, Green, Purple, Carbon, White, Orange*) และ **ตัวถัง 4 แบบ** (*Standard, Scout, Titan, Hoverpod*)
   * **หัวขุด 5 แบบพร้อมสกิลพิเศษ**: *Spiral* (สมดุล), *Vortex* (ขายแร่ `+25%`), *Plasma* (แรงเจาะ `+65%`), *Diamond* (เจาะหินได้ตั้งแต่ Lv.1 + ประหยัดพลังงาน `20%`), *Seismic* (คลื่นกระแทกขุดกว้าง 3 ช่อง)
6. **กราฟิก ไอคอนเวกเตอร์ และเสียงสังเคราะห์ (UI, Particles & Audio)**: HUD 3 โซนด้วย Vector/Sprite Icons, เอฟเฟกต์อนุภาคเศษดิน/ประกายไฟ, และระบบสร้างภาพ PNG / สังเคราะห์เสียง WAV 12 เสียงอัตโนมัติ
7. **ระบบเซฟและแสดงผล (Save/Load & Scaling)**: บันทึก/โหลดเซฟด้วย JSON (`savegame.json`), รองรับโหมดเต็มจอ (`F11`), ย่อ/ขยายหน้าจออัตโนมัติ, ปิด/เปิดเสียง (`M`), และหน้าต่างคู่มือ (`H`/`F1`)
